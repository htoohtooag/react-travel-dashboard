=> Can the Same Google OAuth Client Be Used Elsewhere? 
YES — very important question 👇
Your Google OAuth client is NOT Appwrite-only
    You can use it for:
        - Frontend apps (React, Vue, Flutter)
        - Backend APIs
        - Mobile apps
        - Other auth systems
| Rule                            | Why                                 |
| ------------------------------- | ----------------------------------- |
| Must add correct redirect URIs  | Security                            |
| Client secret must stay private | Never expose in frontend            |
| One client ≠ all platforms      | Web & mobile need different clients |
